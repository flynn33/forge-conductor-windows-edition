# Evidence rules

Evidence grades: source/static, focused test, integrated runtime, stress/profile, independent clean validation. Runtime/installer/leak/performance/UI/live integration claims require runtime evidence.

Command records contain UTC/duration, role/phase/microtask, commit/worktree, executable/args/cwd, nonsecret environment/tool versions, exit/timeout, stdout/stderr paths/hashes, artifacts/hashes, classification and linked gate/feature.

A leak fix requires same-flow before/after, intended lifetime, first product-owned retaining/owner edge, and specific handle/type/path no longer growing. Working set alone is insufficient.
