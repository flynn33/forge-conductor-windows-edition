# Fail-forward policy

Preserve exact failure evidence, classify, reduce, identify first product-owned boundary, apply smallest root-cause fix, rerun same scenario, then adjacent regressions. If environment/external capability remains unavailable, create blocker with retry condition and continue independent work; hard gate remains blocked.

Never hide failure through unbounded retry, sleeps, catch-all success, disabled tests, larger buffers/limits, fabricated metric, guessed path/API, or weakened security/parity.
