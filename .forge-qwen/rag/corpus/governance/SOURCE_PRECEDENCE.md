# Source precedence

1. Owner requirements.
2. Port task contract.
3. Forsetti Agentic Edition.
4. Forsetti Windows public contracts and sealed-runtime rules.
5. macOS source/tests for observable behavior.
6. Package architecture, Qwen execution rules, plans, and gates.
7. Local implementation preference.

The macOS source is behavioral authority, not authority to reproduce Apple-specific mechanisms or audited defects. Qwen must use direct file/source evidence before changing a contract.
