# Forge Conductor for Windows

A native Windows 11 workspace and MCP server for project work with local models in LM Studio.

Version **1.3.19** expands Primary/Fallback to **104 tools** while preserving all original 80 tools, ten specialist playbooks, and five CLU tools. Dedicated web, native DOCX/XLSX/PPTX creation, visible desktop/browser input and capture, PNG drawing/image previews, independent managed workers, and persistent model-task schedules join owner-selected host/workspace filesystem access. The native app design, live telemetry, and existing Primary, Fallback, and CLU integrations remain. Sessions stay LM Studio chats.

Final 1.3.19 committed-source/build/CI, installation, App readback and current-chat acceptance are pending. The installed, unpublished [1.3.18 investigation](Release-1.3.18) passed its local 162-entry suite and exact four-payload/profile upgrade checks, but its Windows CI failed one timeout-message assertion (161/162). Eleven current-chat native calls succeeded; the complete nine-case acceptance and the first managed-recovery final-format check did not qualify the release. These observations remain bound to their original artifact.

The installed, unpublished [1.3.17 investigation](Release-1.3.17) passed its exact source suite and CI, signed upgrade and automatic three-route repair. Current-chat testing then exposed the managed-run context-recovery lease defect; its attempts remain retained without final release qualification, a tag or publication. The unpublished [1.3.16 candidate](Release-1.3.16) passed its source suite/CI, installed with exact payload/profile preservation and completed explicit three-route repair; it was superseded before original/current-chat qualification or publication. The unpublished 1.3.15 candidate's preservation guard refused production MCP routing changed by an isolated test Manager before installation. Earlier engineering checks retain their original source/executable identities. Independent image analysis preserves previews and uses a fresh read-only Responses run. See [Candidate 1.3.19](Release-1.3.19) and [the 1.3.15 investigation](Release-1.3.15) for their separate evidence and limits.
