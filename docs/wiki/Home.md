# Forge Conductor for Windows

A native Windows 11 workspace and MCP server for project work with local models in LM Studio.

Version **1.3.15** expands Primary/Fallback to **104 tools** while preserving all original 80 tools, ten specialist playbooks, and five CLU tools. Dedicated web, native DOCX/XLSX/PPTX creation, visible desktop/browser input and capture, PNG drawing/image previews, independent managed workers, and persistent model-task schedules join owner-selected host/workspace filesystem access. The native app design, live telemetry, and existing Primary, Fallback, and CLU integrations remain. Sessions stay LM Studio chats.

Final 1.3.15 source, installed App and existing-chat qualification are in progress. Earlier engineering checks retain their original source/executable identities. The new independent image-analysis route preserves previews and uses the existing working Responses vision path. See [Release 1.3.15](Release-1.3.15) for the final evidence and limits.

Use the assets attached to [v1.3.15](https://github.com/flynn33/forge-conductor-windows-edition/releases/tag/v1.3.15). Their source commit, package identity, and checksums identify the release artifact. See [Release 1.3.15](Release-1.3.15) for the scope of its actual verification; historical acceptance applies only to its named artifact.

Schedules require Manager to remain running. Future triggers restore after restart; uncertain interrupted effects require an explicitly authorized new attempt. Local Windows notification receipts distinguish submission acceptance from unconfirmed display. Native Office/PNG creation requires neither Office nor Python; generative image providers and cloud accounts remain separately configured connections. Inspect `host_capabilities` and `get_forge_status` for the actual catalog, selected project and owner policy.

Historical Auto Continuity qualification used reserve pressure while the primary MCP worker stayed alive. The 1.3.11 native checks verify observing state and project-scoped recovery; they do not add a new rollover or physical-exhaustion qualification. Interrupted UI handoff after worker eviction remains process-local. See [Continuity](Continuity).
