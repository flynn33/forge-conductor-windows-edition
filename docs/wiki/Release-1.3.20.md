# Version 1.3.20

**Unpublished candidate, superseded by [1.3.21](Release-1.3.21).** The 1.3.20.0 package was installed for qualification. Repeated installed native CMake builds exposed an MSBuild `FileTracker.InitializeCommonApplicationDataPaths` failure before the requested target. Complete native acceptance and publication did not qualify this candidate. Retained checks and failed attempts remain bound to their original 1.3.20 source and package identities.

The superseded unpublished candidate used source version **1.3.20**, with Windows package identity **1.3.20.0** and **106 Primary/Fallback tools**. All previous tools, ten specialist playbooks and five CLU tools remain.

Complete installed/native-model acceptance did not qualify this candidate, and publication did not follow. The [source release notes](https://github.com/flynn33/forge-conductor-windows-edition/blob/main/docs/releases/1.3.20.md) describe its durable CMake/CTest jobs, accessibility paging, optional higher-resolution bounded previews, exact filled rectangle dimensions and observation-error recovery. The [verification record](https://github.com/flynn33/forge-conductor-windows-edition/blob/main/docs/validation/HOST-CAPABILITIES-1.3.20.md) retains the candidate's separate source and failed installed-native observations.

[Version 1.3.19](Release-1.3.19) retains the published historical measurements. Its results are not relabeled as 1.3.20 qualification.
