# Forge Conductor 1.3.18 candidate

The active product version is **1.3.18** and Windows MSIX version is **1.3.18.0**. Final committed source, regression/full-suite results, signed package, installation, original/current-chat acceptance and publication are **pending**. No final success, tag or release download is asserted.

In the superseded 1.3.17 guard, admission reserved continuity state only for the legacy protocol, but completion required that lease whenever successful `context_get` returned recovery evidence. Managed calls use `managed-run-v1`, so their valid packet could be replaced by `integrity_failure`: "The recovered context has no continuity-state lease." The repair restricts legacy recovery bookkeeping and its lease requirement to the legacy protocol. Managed recovery preserves the packet without clearing or annotating unrelated legacy state. Client ownership and canonical request/receipt validation remain unconditional; cancellation, deadlines and authority checks remain.

The focused regression reproduced the missing-lease error on the unchanged guard before the fix. After the one-condition completion change, the existing InvocationGuard CTest entry passed **1/1 in 0.09 seconds** (0.10 seconds total). This is a narrow source check; final committed-source/full-suite, installed and model qualification remain pending.
