# Post-1.0 enhancements

There are no intentionally deferred defects required for the 1.0 Windows x64 product definition.

The following are possible future version features rather than incomplete 1.0 work:

- ARM64 packaging and hardware validation;
- Microsoft Store distribution;
- additional local-model providers and connector breadth;
- expanded long-duration performance and hardware-matrix qualification;
- richer optional browser dashboards and analytics.

Future work must retain schema compatibility, data preservation, Manager ownership, native-tool authority boundaries, accessible GUI behavior, and clean release automation.
