# Forge Conductor 1.3.4 release notes

Version 1.3.4 documents and diagnoses the supported local LM Studio connection contract. Forge Conductor and LM Studio communicate over same-host loopback without authentication. If LM Studio **Require Authentication** is enabled (`json.tokenMode=required`), LM Studio can appear connected while Work Space model discovery and the disposable Responses contract probe fail.

- Work Space model discovery reports HTTP 401/403 as enabled LM Studio authentication and directs the operator to disable Require Authentication.
- The Responses transport returns the Unauthorized error code with the same unauthenticated-loopback requirement.
- Automatic model preparation reports the same corrective action for HTTP 401/403.
- A loopback regression covers the Unauthorized code and guidance returned by model discovery.

This release does not add token persistence, bearer-auth configuration, permissions UI, or an authentication setup wizard. The stable package identity remains `ForgeConductor.Windows`; the product version is `1.3.4` and the package version is `1.3.4.0`.
