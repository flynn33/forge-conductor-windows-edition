# Forge Conductor 1.2.0

Superseded by [1.2.1](1.2.1.md), which fixes missing automatic plugin deployment and guided setup discovery.

## Automatic setup

Choose a project folder, wait for preparation, then describe your task on the same page. Forge Conductor starts the Manager, registers the project, starts an installed LM Studio server when required, loads or reuses a compatible downloaded model, saves its verified selection and checks a response. Retry reuses completed work. Cancel stops pending preparation.

## Development policy

Import a GitHub repository or local source folder, inspect its immutable snapshot, and adopt it for the selected project. Private GitHub access uses existing Git authentication. Imported scripts are never executed.

Adopted policy blocks writes and commands until a human review is recorded. The Manager enforces approved write paths, prohibited paths and exact command arguments through its shared authorization boundary. The new `project_policy.read` tool exposes complete source documents but cannot approve its own review. Updating the adopted revision invalidates the prior review.

## Requirements and limits

Windows 11 x64, LM Studio and a compatible downloaded tool model are required. Setup does not silently download weights or install project dependencies. Human review is required for prose and architectural policy obligations; import is not a semantic compliance certificate. Reviewed shell commands retain the existing native command controls rather than an OS filesystem sandbox.

The package metadata declares its signing identity and whether development signing was used. A development certificate requires explicit trust on machines that do not already trust it.
