# Forge Conductor 1.1.44 — Offline setup help

Engineering prerelease for Windows 11 x64. Package version: `1.1.44.0`.

## Changes

- Twenty searchable offline help articles under Guided setup.
- The opening project-folder action launches the native Windows picker immediately.
- Guide completion wording no longer claims full setup readiness.
- A real-process lifecycle fixture uses an isolated loopback port, allowing tests to run alongside the installed Manager.
- A consolidated readiness-evidence runner builds Release, runs the full CTest suite and static gates, and checks package persistence.
- A source-backed plan covers automatic preparation, policy repository intake, governance enforcement, and complete feature/control qualification.

## Validation and limits

The initial change passed the native Release build, all 151 CTest entries, static gates, and the package-persistence check. Disposable-profile UI checks covered help expansion, search, no-match recovery, the folder picker, and cancellation. Final versioned build/package evidence is supplied with the release assets and their source provenance.

This prerelease does not implement policy repository import/enforcement or the proposed automatic setup coordinator. Complete installed feature/control acceptance, accessibility qualification, independent telemetry comparison, and live continuity proof remain open. UI observations also identified stale Manager detail cards after disconnect and a disposable Manager process that remained after a stop request. These are unresolved findings, not passing release criteria.

The distribution uses the development publisher certificate. Run `Install.ps1 -PreflightOnly` from the extracted bundle and follow its instructions. No production-signing or full production-readiness claim is made. Publishing this candidate does not replace final release acceptance.
