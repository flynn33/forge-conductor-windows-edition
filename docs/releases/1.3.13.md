# Forge Conductor 1.3.13: reliable local-model reviews and evidence workflows

Product version is **1.3.13** and the Windows MSIX version is **1.3.13.0**. Primary and Fallback retain all 80 tools and ten specialist playbooks; CLU retains five governance tools. The native application, three LM Studio integrations, process jobs, continuity, memory, policy, inspection, evidence, and document features remain available.

## Repairs

| Reported issue | Resulting behavior |
|---|---|
| Reviewer receive timeout before provider output | `reviewer_start.receive_timeout_sec` controls each provider Responses request's budget from submission through body completion from 1 to 3,600 seconds, default 600. The chosen value persists in the verified receipt. The asynchronous run continues independently of the admitting MCP request; transport waits observe their own operation deadline and cancellation. Status exposes infrastructure failure separately from the review output. |
| Configured evidence root cannot bind after continuity recovery | Explicit binding resolves through the owning issuer. Later recovery retains the selected project root and explicitly bound owner-configured roots that remain in the current issuer capability. Removed grants, denied paths, and unconfigured directories remain denied. |
| Opening file requires copying into the repository | Supply exactly one authorized `opening_message_path` or bounded inline `opening_message`. Both enforce valid UTF-8, no NUL, and a 65,536-byte bound. File inputs still require active path authority. |
| Shell cwd rejects a Manager-bound directory | Bind the configured directory locally, then use it consistently for synchronous shell, tracked shell, and executable launch. |
| Process launch accepts a cwd shell rejects | Brokered process/tracked-shell cwd is validated and canonicalized before Manager dispatch using the same local authority policy. Manager-only grants do not silently broaden a connector. |
| Nested file write fails opening a directory with Win32 error 5 | Parent-directory creation no longer requests unrelated child-delete/file-creation access. Strict directory sharing, pinned handles, and reparse checks remain. Native file access denials report `filesystem_access_denied` with operation, path, and Win32 code, separate from policy denial. |
| PowerShell command capped at 4,096 bytes | Synchronous and tracked PowerShell accept 65,536 UTF-8 bytes through supervised stdin and fixed launch arguments. Explicit exits, native failure status, nonterminating errors, deadlines, cancellation, and owned process trees remain observable. |

Optional `reviewer_start.mode: "text_only"` omits the tool catalog for reviews of supplied text. Default `tools` mode retains enforced read-only tools. Text-only review identifies missing external evidence as unverified. Infrastructure failure, provider completion, and a review verdict are separate: `gate_approved` remains false, and the task's actual governance requirements still apply.

`get_forge_status` reports reviewer defaults, modes, opening-source bounds, command capacity, active/configured roots, and the effective cwd/recovery policies. Root activation remains explicit after a connector or Manager restart. Shell/executable commands still run with ordinary account permissions; cwd validation does not sandbox absolute arguments or later directory changes.

The CLI also discovers a matching isolated `--alpha-root` Manager for a custom `serve --home` profile, using that profile's deterministic instance names and protected authentication token. It retains same-user authentication and exact home/version checks, enabling the same owned process/reviewer routes in disposable profiles.

## Upgrade

Download the complete distribution from [v1.3.13](https://github.com/flynn33/forge-conductor-windows-edition/releases/tag/v1.3.13), run its non-installing preflight, and install the higher 1.3.13.0 package with the existing stable identity and publisher. Finish owned work before restarting its Manager. Repair all three LM Studio integrations for the intended registered project and reconnect to receive the current schemas. Inspect status and explicitly bind configured external roots in the new connector before filesystem/process work there.

The signed local engineering distribution uses the existing development certificate; its public certificate and installer are included. Production trust and signing remain distinct from local development signing. See [Install](../INSTALL.md), [User guide](../USER-GUIDE.md), and [Windows capability map](../PARITY.md).
