# Forge Conductor 1.2.1

This release corrects the setup and plugin deployment failures in 1.2.0.

- **Start here · Setup** is the first navigation entry. Profiles that have not completed automatic setup open directly in Guided setup, including upgrades with the old guide disabled. Every other page has a visible return-to-setup button.
- Choose a project folder once. Preparation starts the Manager, registers or reuses the project, installs and checks all three LM Studio plugins, opens LM Studio and verifies configuration synchronization, prepares the model, and checks a real response.
- Setup has three numbered sections: automatic preparation, optional development policy, and the first task. An adopted policy still requires its review before project changes.
- **LM Studio plugins** puts installation, repair, connection and results at the top. Detailed process and registration diagnostics are expandable. The page explains how to select plugins in an LM Studio chat.
- Manager maintenance uses its existing narrowly scoped authority independently of project policy. This fixes the private-data-folder denial that prevented plugin installation and maintenance. Project tasks retain the policy gate.
- Run history reflects the observed terminal state instead of retaining a stale running label.

[User guide](../USER-GUIDE.md) · [Verification record](../validation/SETUP-CORRECTION-1.2.1.md)

Windows 11 x64, an installed LM Studio and a compatible downloaded model are required. The supplied MSIX uses the development signing identity declared in distribution.json; its certificate must be trusted before installation. Existing project data and foreign MCP entries are preserved. Plugin synchronization confirms LM Studio has read the configuration; desktop chat tools run when selected for that chat.
