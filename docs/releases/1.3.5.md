# Forge Conductor 1.3.5 release notes

Version 1.3.5 removes Managed Run and implements native LM Studio chat Auto Continuity through the existing Primary, Fallback, and CLU integrations. Sessions stay LM Studio chats. The baseline specialist-session tools remain available; no replacement run manager is introduced.

## Product changes

- Remove Managed Run/readback, Export selected project, Import verify first, the Actions frame/Invoke Tool, Advanced Canonical Catalog, Scope Test, Reset Scope, Apply and Verify, and the old Data Maintenance scheme from product controls/callable routes.
- Preserve Load effective settings, Save and read back, Revert pending edits, Test LM Studio, and Restart Manager. Keep record selection plus button actions in Settings. Add the Continuity packet list, selected details, delete-selection, and clear.
- Return the authoritative project ID/folder and binding source, package paths in execution order, policy source, tool names/count, and agent count through `get_forge_status`. Read a selected package through `instruction_package.read` with revision-bound content paging.
- Bind the selected CLU policy repository immediately from its folder picker. Rename remaining controls to their actions. Send findings to the loaded model through tool-result notifications and show findings in the UI and Activity.
- Observe native LM Studio generation usage, wait for a completed tool boundary, request a detailed model packet, save/publish it, create a successor through product Windows UI Automation, hand over the packet, and verify a subsequent native Forge call.
- Preserve one install/repair action for `forge-conductor`, `forge-conductor-fallback`, and `forge-conductor-clu`. No fourth plugin, Forge-held credential, login step, or model-instruction file is added.
