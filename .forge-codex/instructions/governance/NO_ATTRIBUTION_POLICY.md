# No automated-authorship attribution

Product source, binaries, resources, manifests, installer UI, package metadata, documentation, changelog, release notes, screenshots, telemetry, logs, commits, and tags must not contain automated-authorship attribution.

Blocked examples include:

- generated by an AI or model;
- created with an AI service;
- vendor/model names used as authorship credit;
- co-author trailers for automation;
- bot signatures;
- badges advertising automated generation.

References to model providers are allowed only when they describe product interoperability, configuration, protocol behavior, or diagnostics. Internal `.forge-codex` execution records may identify the tool used to execute work because those records are operational evidence, not public authorship credit.
