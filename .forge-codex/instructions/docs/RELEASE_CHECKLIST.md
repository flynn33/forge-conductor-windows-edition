# Release checklist

- Forsetti profile and manifest validated.
- Source inputs and framework hashes recorded.
- Version synchronized in binaries, manifest, package, CLI, UI, docs, and changelog.
- Release x64 and supported ARM64 builds pass.
- Tests and stress suites pass.
- WPR/resource report passes.
- MCP tool/schema snapshot equals canonical parity.
- Project memory/continuity recovery suite passes.
- LM Studio deployment test passes where host is available.
- Installer lifecycle passes on clean profile.
- Development or release signing class recorded.
- Symbols and checksums generated.
- No-Python, dependency, secret, attribution, and architecture scans pass.
- Documentation and migration guide synchronized.
- Independent compliance report is `pass`.
